## 1. Ներածություն

**Variable Font & Dynamic Parameter Controller (VF 2.0)**-ը մասնագիտացված CEP (Common Extensibility Platform) ընդլայնում է Adobe Illustrator-ի համար (CC 2018–CC 2025+)։ Այն նախատեսված է OpenType փոփոխական տառատեսակների (Variable Fonts) բոլոր հնարավոր առանցքները (Քաշ, Լայնություն, Թեքություն, Օպտիկական չափ և այլն) և վեկտորային դինամիկ պարամետրերը ճշգրիտ, իրական ժամանակում և ոչ-գծային ալգորիթմներով կառավարելու համար։

### Հիմնական Առավելությունները
- **3 Մասնագիտացված Ռեժիմներ**՝ 1D սահիչներ անհատական բացվող կորերով, Պրոֆեսիոնալ Բազմակետային Արվեստանոց (Spline Studio) և 2D Կարտեզյան նախագծման դաշտ։
- **Իրական Ժամանակի Գերարագ Կապ**՝ `requestAnimationFrame` թրոթլինգով և ֆոնային պոլինգի խելացի դադարեցմամբ մկնիկի քաշման պահին, ինչը երաշխավորում է 60 FPS սահունություն։
- **Երկլեզու Համակարգ (i18n)**՝ Հայերեն (ՀԱՅ) և Անգլերեն (EN)՝ ավտոմատ լեզվի ճանաչմամբ և ակնթարթային փոխարկմամբ։
- **Ինտերակտիվ Ուսուցում (Interactive Tour Guide)**՝ 7-քայլանի ներկառուցված վիզուալ գիդ, որը սովորեցնում է վահանակի բոլոր հնարքները։
- **Բրաուզերային Սիմուլյացիա (Standalone Simulation)**՝ Կարող է աշխատել ցանկացած վեբ բրաուզերում (Chrome, Edge, Firefox) առանց Illustrator-ի՝ փորձարկման և ցուցադրման համար։
- **Մոդուլային Դասավորություն (Modular Dockable Panels)**՝ Արվեստանոցի յուրաքանչյուր բաժին կարելի է տեղափոխել, ծալել, փակել կամ վերականգնել «Պատուհան» մենյուից։

## 2. Տեղադրում և Գործարկում

### Ավտոմատ Տեղադրում (Ամենահեշտ տարբերակը)

#### Windows-ում․
1. Փակեք Adobe Illustrator-ը։
2. Կրկնակի կտտացրեք **`install.bat`** ֆայլի վրա (կամ աջ կտտոցով ընտրեք *Run with PowerShell* `install.ps1`-ի համար)։
3. Ծրագիրն ինքնուրույն․
   - Գրանցամատյանում (Registry) կմիացնի `PlayerDebugMode`-ը CSXS 7-ից մինչև CSXS 16 տարբերակների համար։
   - Ընդլայնումը կպատճենի `%APPDATA%\Adobe\CEP\extensions\com.illustrator.variables.panel` թղթապանակում։
4. Բացեք Illustrator-ը և վերին մենյուից ընտրեք՝ **Window > Extensions > Variable Controller**։

#### macOS-ում․
1. Բացեք Terminal-ը ընդլայնման թղթապանակում։
2. Գործարկեք հրամանը՝
   ```bash
   chmod +x install.sh && ./install.sh
   ```
3. Բացեք Illustrator-ը՝ **Window > Extensions > Variable Controller**։

### Գործարկում Figma-ում (Figma Native Plugin)
1. Բացեք **Figma Desktop**-ը կամ Figma-ն բրաուզերում։
2. Վերին մենյուից ընտրեք՝ **Plugins > Development > Import manifest from manifest.json...**
3. Ընտրեք `manifest.json` ֆայլը, որը գտնվում է այս ընդլայնման արմատային թղթապանակում (`Variables Plugin/manifest.json`)։
4. Գործարկեք **Variable Font & Dynamic Parameter Controller**-ը Figma-ում կամ FigJam-ում։
5. Վահանակի վերին ոճի կոճակով (🌓) կարող եք ընտրել Adobe Spectrum կամ **Figma Design Language (Figma Dark / Figma Light)** ոճերը։

---

### Ձեռքով Կարգավորում (Manual Setup)
Եթե նախընտրում եք տեղադրել ձեռքով․
1. **Միացրեք Debug Mode-ը (Windows PowerShell-ով որպես Admin)․**
   ```powershell
   7..16 | ForEach-Object {
       Set-ItemProperty -Path "HKCU:\Software\Adobe\CSXS.$_" -Name "PlayerDebugMode" -Value "1" -Force
   }
   ```
2. **Պատճենեք ընդլայնման պանակը հետևյալ հասցեով․**
   - **Windows:** `C:\Users\<Օգտատեր>\AppData\Roaming\Adobe\CEP\extensions\Variables Plugin`
   - **macOS:** `~/Library/Application Support/Adobe/CEP/extensions/Variables Plugin`

### Բրաուզերում Փորձարկում (Առանց Illustrator-ի)
Կրկնակի կտտացրեք **`index.html`** ֆայլին Chrome-ում կամ Edge-ում։ Համակարգը կակտիվացնի ներկառուցված Bridge սիմուլյատորը, ինչը թույլ է տալիս փորձարկել կորերը, բաշխումները, 2D դաշտը և տառատեսակի փոփոխությունները։

## 3. Վահանակի Գլխամասը և Ընտրության Ինտելեկտուալ Համակարգը

Վահանակի վերին հատվածը ապահովում է մշտական հսկողություն ընթացիկ վիճակի և համակարգային գործիքների նկատմամբ․

### Գլխամասի Գործիքներ
1. **«Պատուհան» (Window Menu)**․
   - Բացվող ցանկ, որտեղից կարող եք միացնել կամ անջատել Արվեստանոցի 6 հիմնական բաժինները (Կորերի Շերտեր, Կարգավորումներ, Սպլայն Կտավ, Կետեր, Նախադրվածքներ, Բաշխման Նախադիտում)։
   - **«↺ Վերականգնել Դիրքերը»** — վերականգնում է բոլոր բաժինների նախնական հերթականությունը և բացում բոլոր փակված փեղկերը։
   - **«🎓 Ուսուցում»** — վերագործարկում է ինտերակտիվ քայլ առ քայլ ուղեցույցը։
2. **Լեզվի Փոխարկիչ («ՀԱՅ / EN»)**․
   - Թույլ է տալիս մեկ կտտոցով փոխել ամբողջ ինտերֆեյսը, հուշումները, կոճակներն ու հաղորդագրությունները հայերենի և անգլերենի միջև։ Ընտրված լեզուն պահպանվում է `localStorage`-ում։
3. **«↻» Սինխրոնիզացիա**․
   - Ձեռքով թարմացնում է Illustrator-ում ընտրված օբյեկտների տվյալները։ (Համակարգն ունի նաև ավտոմատ ֆոնային ստուգում 400մվ պարբերականությամբ)։

### Ընտրության Կարգավիճակներ (Selection Intelligence)
- **Ակտիվ Փոփոխական Տառատեսակ (Կանաչ կետիկ)**․
  - Ցույց է տալիս տառատեսակի ընտանիքը և տեքստի նիշերի կամ առարկաների քանակը։
- **Ոչինչ Ընտրված Չէ (Empty Selection Card)**․
  - Եթե Illustrator-ում ոչինչ ընտրված չէ, գործիքների փոխարեն ցուցադրվում է ինֆորմացիոն քարտ՝ փաստաթղթում առկա **բոլոր տեքստային շերտերի ցանկով**։
  - Յուրաքանչյուր տեքստ ունի **`Փոփոխական`** (Variable) կամ **`Ստատիկ`** (Static) նշում։
  - Կտտացնելով ցանկացած տեքստի վրա՝ այն **անմիջապես ընտրվում է Illustrator-ի փաստաթղթում**։
- **Ստատիկ Տառատեսակի Նախազգուշացում (Non-Variable Font Warning)**․
  - Եթե ընտրված է սովորական տառատեսակ (օր․՝ Arial, Times New Roman), վահանակը զգուշացնում է, որ այն չունի փոփոխական առանցքներ, և առաջարկում է ընտրել Variable Font (օր․՝ *Bahnschrift*, *Acumin Variable Concept*, *ArTarumianAzdVar*)։
- **Ապանշված Վիճակ (Deselected State Retention)**․
  - Տեքստը կտավում ապանշելիս (Deselect) վերջին կարգավորված պարամետրերը չեն կորչում և պահպանվում են հիշողության մեջ։

## 4. Ռեժիմ 1․ Սահիչներ եւ Կորեր (Sliders & Curves — 1D)

Այս ռեժիմը նախատեսված է տառատեսակի յուրաքանչյուր առանցքը առանձին-առանձին կառավարելու համար՝ ստանդարտ սահիչներով և ներկառուցված անհատական Բեզյե կորերով։

### Հնարավորությունները և Գործիքները
1. **Հարթ HD Սահիչներ (Sliders)**․
   - Իրական ժամանակում սահուն փոխում են առանցքի արժեքը (օր․՝ Weight 100..900, Width 50..200, Slant -15..0°):
2. **Բարձր Ճշգրտության Թվային Դաշտեր (Stepper Inputs)**․
   - Թույլ են տալիս ստեղնաշարից մուտքագրել ցանկացած կոնկրետ թիվ (օր․՝ `637` կամ `12.5`)։ Թիվը հավաքելիս արժեքը վաղաժամ չի կտրվում, իսկ Enter սեղմելիս դաշտը հաստատվում է։
3. **«↺» Վերականգնել Լռելյայնը**․
   - Յուրաքանչյուր առանցք ունի իր «↺» կոճակը, որը վերադարձնում է տվյալ առանցքի գործարանային լռելյայն արժեքը (Default):
4. **Քաշի Արագ Նախադրվածքներ (Weight Presets Bar)**․
   - Եթե տառատեսակն ունի `wght` առանցք, ցուցադրվում է արագ կոճակների շարք՝
     - **Thin (100)**
     - **Light (300)**
     - **Regular (400)**
     - **Bold (700)**
     - **Black (900)**
   - **«↺ Վերականգնել Regular (400 / 100)»** — մեկ հպումով բոլոր առանցքները վերադարձնում է ստանդարտ Regular ոճի։
5. **Անհատական Բեզյե Կորի Դարակ («Կոր» / Toggle Curve Drawer)**․
   - Յուրաքանչյուր սահիչի աջ մասում կա **«Կոր»** կոճակ։ Սեղմելիս բացվում է տվյալ առանցքի անհատական ոչ-գծային բաշխման դարակը։
   - **Ինտերակտիվ Բեզյե Կտավ**՝ կարող եք մկնիկով քաշել P1 և P2 շոշափող լծակները։
   - **Կոորդինատների Ուղիղ Մուտքագրում**՝ P0 (Սկիզբ), P1 (X, Y), P2 (X, Y), P3 (Վերջ)։
   - **Արագ Նախադրվածքներ**՝ Գծային (Linear), Ease-In, Ease-Out, S-Կոր (S-Curve), Զանգ (Bell)։
   - **Կորի Պատճենում Այլ Առանցքի Վրա («Պատճենել կորը դեպի...»)**՝ հնարավորություն է տալիս կարգավորած գեղեցիկ կորը մեկ կտտոցով տեղափոխել մեկ այլ առանցքի վրա (օրինակ՝ Weight-ի կորը կրկնօրինակել Width-ի վրա)։
   - **Բաշխման Կենդանի Նախադիտում**՝ ցուցադրում է ուղղաձիգ գծիկներով սպեկտր, թե ինչպես է տվյալ կորը տարածվում տեքստի տառերի կամ ընտրված առարկաների վրա։

## 5. Ռեժիմ 2․ Արվեստանոց (Graph Studio — Multi-Point Spline)

**Արվեստանոցը** համակարգի ամենահզոր ստեղծագործական միջավայրն է։ Այն հնարավորություն է տալիս կառուցել բարդ բազմակետային սպլայն-կորեր, միաժամանակ կառավարել մի քանի առանցքների կորեր տարբեր շերտերով և ստեղծել կինեմատոգրաֆիկ տպագրական անցումներ։

### 1. Բազմակորային Համակարգ (Multi-Curve Layers)
- **Միաժամանակյա Բազմառանցքային Բաշխում**․ Դուք կարող եք նույն տեքստի վրա ունենալ անկախ կոր Weight-ի համար, այլ կոր Width-ի համար, և 3-րդ կոր Slant-ի համար։
- **Կորերի Պիտակներ (Curve Pills)**․ Յուրաքանչյուր կոր ունի իր յուրահատուկ գույնը (Կապույտ, Ծովագույն, Մանուշակագույն, Նարնջագույն, Վարդագույն, Զմրուխտ)։
- **«+ Ավելացնել Կոր»**․ Ավելացնում է նոր կոր տառատեսակի մնացած ազատ առանցքներից մեկի համար։
- **Կորի Միացում/Անջատում (Աչքի կոճակ)**․ Թույլ է տալիս ժամանակավորապես անջատել որևէ առանցքի ազդեցությունը՝ առանց կորը ջնջելու։
- **Առանցքների Փոխանակում (Swap Axes)**․ Թույլ է տալիս փոխել ակտիվ կորի առանցքը կամ տեղերով փոխել այլ կորի հետ։

### 2. Բազմակետային Սպլայն Կտավ և Մաթեմատիկական Մոդել
- **Newton-Raphson Խորանարդ Ինտերպոլացիա**․ Յուրաքանչյուր հատված լուծվում է Y(X) պարամետրիկ հավասարմամբ՝ ապահովելով մաթեմատիկորեն ճշգրիտ բաշխում։
- **Ազատ Կետեր (Multi-Point Support)**․ Ի տարբերություն ստանդարտ 2-կետանի կորերի, այստեղ կարող եք ունենալ կամայական թվով միջանկյալ խարսխակետեր։
- **Խարսխակետերի Տեղաշարժ**․ Մկնիկով կարող եք բռնել և ազատ տեղաշարժել ցանկացած կետ X և Y ուղղություններով։

### 3. Լծակների Մասնագիտացված Կառավարում (Handles Engine)
- **Սահուն Լծակներ (Smooth Handles)**․ Լծակները գտնվում են մեկ ուղղի վրա և շարժվում են սիմետրիկորեն՝ ապահովելով կատարյալ հարթ շրջադարձեր։
- **Կոտրված Լծակներ (Broken Handles / Cusp)**․
  - **Ինչպե՞ս միացնել**․ Կրկնակի կտտացրեք լծակի գնդիկի (Handle Knob) վրա։
  - Լծակի կապը հանդիպակաց կողմի հետ խզվում է, ինչը թույլ է տալիս ստանալ սուր գագաթներ, ատամնաձև կամ զիգզագաձև անցումներ։
  - Կրկին կրկնակի կտտացնելով՝ լծակը վերադառնում է սահուն վիճակի։
- **Ուղիղ Գծեր (Straight Lines / No Handles)**․
  - **Ինչպե՞ս միացնել**․ Սեղմած պահեք Alt ստեղնը և կատարեք **Աջ Կտտոց (Right Click)** լծակի կամ խարսխակետի վրա։
  - Լծակները լիովին վերանում են, իսկ հարակից հատվածները դառնում են **բացարձակ ուղիղ գծային սեգմենտներ**։
  - Կրկին Alt + Աջ կտտոցով սահուն լծակները ակնթարթորեն վերականգնվում են։

### 4. Կետերի Ավելացում, Ջնջում և Ստեղնաշարային Հնարքներ
- **Կետ ավելացնել**․
  - Կրկնակի կտտոց կտավի դատարկ հատվածում (կամ «+ Ավելացնել Կետ» կոճակով)։
- **Կետ ջնջել**․
  - Կրկնակի կտտոց միջանկյալ կետի վրա (կամ սեղմեք Delete / Backspace, կամ «✕ Հեռացնել» կոճակը)։
- **Պատմության Հետարկում / Վերարկում (Undo / Redo)**․
  - Մինչև 50 քայլ հիշողություն՝ կետերի ավելացման, ջնջման, տեղաշարժման կամ լծակների փոփոխության համար։
  - Ստեղներ՝ Ctrl+Z (Հետարկել), Ctrl+Y կամ Ctrl+Shift+Z (Վերարկել)։

### 5. Կետերի Ճշգրիտ Տեսուչ (Point Inspector) & Չիպեր
- Վերևում գտնվող **[P0], [P1], [P2]...** չիպերով կարող եք արագ անցնել ցանկացած կետի։
- Տեսուչում ցուցադրվում են կետի ճշգրիտ X և Y արժեքները (0.000 .. 1.000), ինչպես նաև կարգավիճակը՝ *«Սահուն լծակներ»*, *«Կոտրված լծակներ»* կամ *«Ուղիղ / Առանց լծակների»*։

### 6. Նախադրվածքների և Պանակների Համակարգ (Presets & Folders)
Արվեստանոցն ունի հարուստ մաթեմատիկական գրադարան․
- **Ներկառուցված Կորեր**․
  - **Գծային (Linear)** — հավասարաչափ աճող։
  - **Ease-In / Ease-Out** — դանդաղ սկիզբ կամ դանդաղ ավարտ։
  - **S-Կոր (S-Curve)** — սահուն սիգմոիդալ անցում։
  - **Զանգ (Bell Curve)** — գաուսյան գմբեթ, կենտրոնում հասնում է առավելագույնի։
  - **Հովիտ (Valley)** — հակառակ զանգ, կենտրոնում նվազագույնն է։
  - **Ալիք (Wave)** — սինուսոիդալ հարթ տատանում։
  - **Բազմալիք (Ripple)** — կրկնակի արագ ալիքներ։
  - **Աստիճանաձև (Steps)** — կտրուկ աստիճաններով անցումներ։
  - **Ցատկ (Bounce)** — ֆիզիկական ցատկի ազդեցություն։
  - **Առաձգական (Elastic)** — զսպանակաձև տատանում։
  - **Սայր (Peak)** — սուր գագաթ կենտրոնում։
  - **Զարկ (Pulse)** — էլեկտրասրտագրի նմանվող պուլսացիա։
  - **Էքսպոնենտ (Expo)** — կտրուկ արագացող աճ։
- **Պանակների Կառավարում (Folders)**․
  - Կարող եք ստեղծել սեփական պանակներ («＋ Նոր Պանակ»)՝ ձեր կորերը թեմատիկ խմբավորելու համար։
- **Սեփական Կորերի Պահպանում («＋ Ստեղծել Preset»)**․
  - Ցանկացած ձևափոխված կոր կարող եք պահպանել ձեր ընտրած անունով և նշանակել կոնկրետ պանակում։
- **Արտածում և Ներածում (Export / Import JSON)**․
  - **«⤓ Արտածել»** — բոլոր սեփական preset-ները պահպանում է `.json` ֆայլի մեջ։
  - **«⤒ Ներածել»** — թույլ է տալիս բեռնել նախկինում արտածված կամ այլ դիզայներների ստեղծած preset-ների հավաքածուները։

### 7. Բաշխման Ինտերակտիվ Նախադիտում և Կորագծի Պրոյեկցիաներ (Live Distribution & Curve Projections)
- Տեղակայված է անմիջապես «Սպլայն Կտավ»-ի մեջ՝ գրաֆի տակ։
- Յուրաքանչյուր տառ կամ օբյեկտ ներկայացված է ուղղաձիգ բաշխման գծիկով։
- **Ինտերակտիվ Զուգահեռներ և Պրոյեկցիա (Hover)**․ Մկնիկը պահելով բաշխման ցանկացած գծի վրա՝ կտավի վրա գծվում են ուղղահայաց և հորիզոնական զուգահեռ պրոյեկցիոն գծեր դեպի կորագիծ, կորի վրա լուսարձակում է հատման կետը և ցուցադրվում է ճշգրիտ թվային պիտակ (Badge)՝ տվյալ տառի ու առանցքի արժեքով։

### 8. Փեղկերի Կառավարում (Modular Layout Management)
Արվեստանոցի յուրաքանչյուր բաժին ինքնուրույն մոդուլ է․
- **Տեղափոխում (Reorder)**․ Բռնեք վերնագրի ձախ կողմում գտնվող **«⠿»** կետիկներից և քաշեք վերև կամ ներքև։
- **Ծալում/Բացում (Collapse/Expand)**․ Կտտացրեք բաժնի վերնագրին կամ նետիկին (▼)՝ այն ծալելու և աշխատանքային տարածք ազատելու համար։
- **Փակում (Close)**․ Սեղմեք **«✕»** կոճակը բաժինը թաքցնելու համար։ Կարող եք ցանկացած պահի այն նորից ակտիվացնել գլխամասի **«Պատուհան»** մենյուից։

## 6. Ռեժիմ 3․ 2չափ Դաշտ (2D Design Space Field)

Այս ռեժիմը նախատեսված է տառատեսակի երկու հիմնական առանցքները միաժամանակ, 2D հարթության մեջ ինտուիտիվ կառավարելու համար (օրինակ՝ X = Քաշ / Weight, Y = Թեքություն / Slant կամ Լայնություն / Width)։

### Հնարավորությունները և Գործիքները
1. **Քառակուսի 2D Հարթություն (1:1 Proportional Grid)**․
   - Կտավն ավտոմատ պահպանում է կատարյալ քառակուսի համաչափությունը էկրանի ցանկացած չափսի դեպքում։
2. **Առանցքների Խելացի Փոխարինում**․
   - Եթե X-ի բացվող ցանկում ընտրեք այն նույն առանցքը, ինչ արդեն ընտրված է Y-ում, համակարգն ավտոմատ տեղերով կփոխի դրանք՝ բացառելով կրկնությունը։
3. **Ինտերակտիվ Քաշվող Նշանոց (Draggable Crosshair Node)**․
   - Դաշտի կենտրոնական կետը շարժելիս ցուցադրվում են կետագծային պրոյեկցիաներ դեպի X և Y առանցքները՝ ուղիղ եթերում ցույց տալով ընթացիկ արժեքները։
4. **4 Անկյունային Վարպետ-Խարիսխներ (Master Badges — TL, TR, BL, BR)**․
   - Կտավի չորս անկյուններում գտնվում են պիտակներ, որոնք խորհրդանշում են տառատեսակի 4 ծայրահեղ վարպետ-ոճերը (օր․՝ Thin-Condensed, Thin-Expanded, Black-Condensed, Black-Expanded)։
   - **Կտտացնելով ցանկացած անկյան վրա**՝ նշանոցն ակնթարթորեն թռչում է այդ ծայրահեղ կետը։
5. **Արագ Կոճակներ**․
   - **«↺ Regular»** — վերականգնում է ստանդարտ արժեքները (Weight 400, Width 100)։
   - **«✛ Կենտրոն» (Snap to Center)** — նշանոցը տեղափոխում է կենտրոնական (0.5, 0.5) մեդիան դիրքը։

## 7. Վեկտորային Առարկաների Կառավարում (Dynamic Vector Shapes)

Համակարգը սահմանափակված չէ միայն տեքստերով։ Եթե Illustrator-ում ընտրեք ոչ թե տեքստ, այլ սովորական **վեկտորային ուղիներ (Path Items)** կամ պատկերներ․
1. Համակարգն ավտոմատ ճանաչում է ընտրված վեկտորները։
2. Առանցքների փոխարեն հասանելի են դառնում վեկտորային դինամիկ պարամետրերը․
   - **Եզրագծի Հաստություն (Stroke Width)** — 0.5 pt -ից մինչև 50 pt։
   - **Թափանցիկություն (Opacity)** — 0% -ից մինչև 100%։
3. **Կորերի Բաշխում Առարկաների Վրա (Map across Items)**․
   - Ընտրելով մի քանի առարկաներ (օրինակ՝ 20 զուգահեռ գծեր) և կիրառելով S-Կոր կամ Ալիք՝ գծերի հաստությունը կամ թափանցիկությունը կբաշխվի ըստ այդ կորի՝ ստեղծելով օպտիկական գրաֆիկական էֆեկտներ։

## 8. Ստեղնաշարային Կոմբինացիաներ և Գործողություններ

| Ստեղնաշար / Մկնիկ | Գործողություն | Որտե՞ղ է գործում |
| :--- | :--- | :--- |
| **Կրկնակի Կտտոց Դատարկ Տեղում** | Ավելացնել նոր խարսխակետ ճշգրիտ կոորդինատներով | Արվեստանոցի Կտավում |
| **Կրկնակի Կտտոց Կետի Վրա** | Ջնջել ընտրված միջանկյալ կետը | Արվեստանոցի Կտավում |
| **Կրկնակի Կտտոց Լծակին (Handle)** | Փոխարկել Սահուն ⇄ Կոտրված (Smooth ⇄ Broken) | Արվեստանոցի Կտավում |

| **Delete կամ Backspace** | Հեռացնել ընտրված կետը | Արվեստանոց |

## 9. Ճարտարապետական Նրբություններ և Ինժեներական Լուծումներ

### 1. Character Style-ի Աղտոտման Կանխարգելում (`cleanDefaultCharacterStyle`)
Illustrator-ում սովորական սկրիպտերով տառատեսակի ատրիբուտները փոխելիս հաճախ փաստաթղթի լռելյայն Character Style-ը կեղտոտվում է պատահական եզրագծերով (rogue strokes) կամ ծայրահեղ պարամետրերով։ Մեր ExtendScript շարժիչը պարունակում է ներկառուցված ֆիլտր, որը պաշտպանում է փաստաթղթի ոճերը։

### 2. Տառատեսակների AxisVector-ի Խելացի Քարտեզագրում (`getFamilyAxisMapping`)
Տարբեր տառատեսակների մշակողներ (Adobe, Google, Monotype և այլն) OpenType աղյուսակներում առանցքները դասավորում են տարբեր հերթականությամբ (օրինակ՝ մեկի մոտ `[wdth, wght]` է, մյուսի մոտ՝ `[wght, wdth]`)։ Մեր հոսթ շարժիչը դինամիկ կերպով ստուգում է յուրաքանչյուր տառատեսակի ներքին կառուցվածքը և ապահովում 100% ճշգրիտ համապատասխանություն։

### 3. Ատոմային Undo Տրանզակցիաներ Illustrator-ում
Երբ սահիչը կամ կորը շարժում եք, Illustrator-ում չեն ստեղծվում հարյուրավոր միջանկյալ Undo քայլեր։ Բոլոր փոփոխությունները կատարվում են խմբավորված, ինչի շնորհիվ Illustrator-ում Ctrl+Z սեղմելիս ձեր ամբողջական գործողությունը չեղարկվում է մաքուր՝ մեկ քայլով։

## 10. Հաճախ Տրվող Հարցեր և Խնդիրների Լուծում (Troubleshooting & FAQ)

#### Հարց 1․ Ինչո՞ւ Illustrator-ի Window > Extensions մենյուում չի երևում «Variable Controller»-ը։
**Պատասխան**․
1. Համոզվեք, որ Illustrator-ը ամբողջությամբ փակել եք տեղադրելուց առաջ։
2. Ստուգեք, որ ընդլայնման պանակը գտնվում է ճիշտ տեղում (`%APPDATA%\Adobe\CEP\extensions\`)։
3. Ստուգեք, որ Windows Registry-ում `PlayerDebugMode`-ը միացված է (`1`) ձեր Illustrator-ի տարբերակին համապատասխանող CSXS բաժնում (օր․՝ CSXS.11 կամ CSXS.12):

#### Հարց 2․ Ինչո՞ւ է տառատեսակն ընտրելիս գրվում «Ոչ փոփոխական տառատեսակ (Ստատիկ)»։
**Պատասխան**․  
Ձեր ընտրած տառատեսակը ստանդարտ ստատիկ տառատեսակ է (օր․՝ Arial, Tahoma, Georgia), որը չունի OpenType 1.8+ Variable Font առանցքներ։ Ընտրեք փոփոխական տառատեսակ, օրինակ՝ *Bahnschrift* (Windows-ի ներկառուցված), *Acumin Variable Concept*, *Minion Variable Concept*, *Myriad Variable Concept*, կամ հայերեն փոփոխական տառատեսակ՝ *ArTarumianAzdVar*։

#### Հարց 3․ Ինչպե՞ս կարող եմ բացել Developer Tools (Console) պատուհանը սխալները տեսնելու համար։
**Պատասխան**․  
Ընդլայնման մեջ առկա է `.debug` ֆայլը։ Բացեք Google Chrome բրաուզերը և հասցեի տողում մուտքագրեք՝  
`http://localhost:8088`  
Այստեղից կարող եք բացել Chrome DevTools-ը և ուղիղ հետևել JavaScript կոնսոլին և ցանցային հարցումներին։

#### Հարց 4․ Կարո՞ղ եմ իմ ստեղծած կորերը տեղափոխել ուրիշ համակարգիչ։
**Պատասխան**․  
Այո՛։ Արվեստանոցում սեղմեք **«⤓ Արտածել»** (Export) կոճակը։ Կներբեռնվի `.json` ֆայլ։ Մյուս համակարգչում պարզապես բացեք վահանակը և սեղմեք **«⤒ Ներածել»** (Import)՝ ընտրելով այդ ֆայլը։
